# Data Cleaning with Python

## Introduction
In this analysis, data cleaning was performed on medical readmission data using the programming language Python. 
To understand the groups affected, the dataset on medical readmission must be cleaned.

Research question: What patient demographic is at the highest risk for readmission? 

## Technologies Used
- Python (NumPy, MissingNo, SciPy, Seaborn, Scikit-learn)
- Jupyter Notebook 

## Data
medical_raw_data.csv

## Usage
1. Detecting and treating duplicate values
2. Detecting and treating missingness
3. Detecting and treating null values
4. Detecting and treating outliers
5. Data manipulation  
6. Data visualization
7. Principal Component Analysis (PCA) for dimensional reduction
