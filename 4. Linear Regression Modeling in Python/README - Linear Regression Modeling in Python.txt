# Linear Regression Modeling in Python

## Introduction
This project involves analyzing medical readmission data using Python and linear regression modeling.

## Research Question
How successfully can we predict a patient’s length of stay based on his or her medical conditions? 

## Technologies Used
- Python (NumPy, Pandas, Matplotlib, Seaborn, Statsmodels and Scikit-learn)
- Jupyter Notebook

## Data 
medical_clean.csv

## Usage
1. Linear Regression
2. Data Visualization
3. Recursive Feature Elimination (RFE)

## Multiple Linear Regression Assumptions:
1) Linearity: A linear relationship exists between the independent variable, x, and the dependent variable, y.
2) Multicollinearity: There should not be highly correlated variables between the independent variables.
3) Independence of Observations: The observations are random and independent.
4) Normality of Residuals: The residuals of the model have normal distribution.
5) Homoscedasticity: Error does not change across all the values of the independent variables, meaning there is homoscedasticity and variance at every x is constant for the residuals.
