# Customer Segmentation with K-Means Clustering

## Introduction
Customer segmentation involves dividing consumers into groups based on shared characteristics, such as demographics, preferences, behaviors, or psychographics 
The primary goal of this analysis is to use K-means clustering to gain a deeper understanding of telecom customer characteristics by analyzing their behavior. 
By clustering customers based on tenure and monthly charges, we can identify distinct patterns in service usage and payment behaviors, enabling the development of more effective targeted marketing strategies and personalized retention efforts.

## Research Question
How can K-means clustering on customer tenure and monthly charges in a churn dataset be applied to segment customers? 

## Technologies Used
- Python (pandas, numpy, matplotlib, seaborn, scipy, sklearn)
- Jupyter Notebook 

## Data Sources
The data used in this project comes from the [Kaggle Sales Dataset](https://www.kaggle.com/datasets).

## Usage
1. Data preprocessing
2. Elbow plot
3. K-means clustering
4. Quality of clustering technique

## Results
The customer segments and behaviors were identified by the four distinct clusters. 
These clusters represent the following customer types:
1. Short-tenure, low-payment customers
2. Short-tenure, high-payment customers
3. Long-tenure, low-payment customers
4. Long-tenure, high-payment customers
