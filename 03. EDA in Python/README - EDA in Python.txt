# Exploratory Data Analysis (EDA) in Python

## Introduction
This project involves analyzing medical readmission data using Python and the Chi-Square test for correlation.

## Research Question
What independent variable was most correlated to the readmission of medical patients?

## Technologies Used
- Python (NumPy, Pandas, Matplotlib, Seaborn, and SciPy)
- Jupyter Notebook 

## Data 
medical_clean.csv

## Usage
1. Exploratory Data Analysis (EDA)
2. Chi-Square Test
3. Univariate Statistical Analysis
4. Bivariate Statistical Analysis

## Results 
The highest correlated variable was determined to be Services.
 
The Services variable had a Chi-Square statistic value of about 8.89, p-value of around 0.03, 
and three degrees of freedom. 

Since the p-value was less than alpha, 0.05, the correlation was statistically significant.
