# Logistic Regression Modeling in Python

## Introduction
This project involves analyzing medical readmission data using Python and linear regression modeling.

## Research Question
How successfully can we predict a patient’s length of stay based on his or her medical conditions? 

## Technologies Used
- Python (NumPy, Pandas, Matplotlib, Seaborn, Statsmodels and Scikit-learn)
- Jupyter Notebook 

## Data 
medical_clean.csv

## Usage
1. Logistic Regression
2. Data Visualization
3. Recursive Feature Elimination (RFE)

## Multiple Logistic Regression Assumptions:
1. Logical Dependent Variable: The response variable should be a logical categorical variable.
2. Multicollinearity: Independent variables should not be highly correlated with each other.
3. Independence of Observations: The observations are independent and random.
4. Linearity: The independent variables should be related linearly to the log odds.
